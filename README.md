Quake 4 Zombie Survival Mod
Created by Alexander Azevedo

Overview

This mod changes Quake 4 into a zombie-style survival experience where you try to kill zombies as they progressivly spawn more and more until you survive all of the rounds or die.

Current Features

- 10 modified weapons
- Zombie wave spawning system
- Zombies dropping weapons
- Five perks
- Mystery box for weapons

Weapons

1. Blaster – Lumina
2. Machinegun – MK 67
3. Shotgun – Doof Doof
4. Hyperblaster – Ray Gun
5. Grenade Launcher – War Machine
6. Nailgun – L-STAR
7. Rocket Launcher – Bazooka
8. Railgun – Barrett
9. Lightning Gun – Volt Driver
10. Dark Matter Gun – Gravity Gun

Perks / Powerups
The mod includes five custom perks:

- Guard
- Haste
- Doubler
- Regen
- Ammo Regen
